## 🌸 About The Portfolio

This portfolio represents my engineering mindset and creative craft as an **Information Technology & Management undergraduate at University of Moratuwa** (GPA: 3.56). It showcases full-stack web applications, enterprise Spring Boot microservices, IoT systems, and verified industry credentials.

### ✨ Key Features & Interactions

* **🎨 Bespoke Pastel & Editorial Design System:** Curated palette blending rose pinks (`#FB5B86`, `#FF85A2`), soft lavender, and rich dark hues.
* **🌓 Seamless Dark / Light Mode:** Persistent theme context with instant visual transitions across cards, typography, and contrast elements.
* **✨ Magic Star & Stardust Particle Cursor:** Custom HTML5 Canvas cursor engine replacing the standard pointer on desktop with an animated 4-point star, smooth physics trailing ring, hover expansion, and interactive click bursts.
* **🌌 Floating Ambient Bokeh Blobs:** Multi-layered, GPU-accelerated background aura orbs with organic keyframe float cycles.
* **🍱 Bento Grid Architecture:** Academic metrics, core projects, and technical skills arranged in a responsive, modern bento layout.
* **📱 Ultra Responsive:** Fluid layout scaling seamlessly from 4K ultrawide monitors down to mobile devices.
* **⚡ 100% Type-Safe:** Built with strict TypeScript checks, Next.js App Router, and Turbopack.

## 🚀 Getting Started Locally

### Prerequisites
* **Node.js**: `v18.17` or higher
* **npm**, **pnpm**, or **yarn**

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Ruhini-Udara/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Open in browser:**
   Navigate to [http://localhost:3000](http://localhost:3000) to view the portfolio.

### Production Build

To test the production Turbopack build:
```bash
npm run build
npm run start
```
